# 决策板视觉重构 V2 · 设计规范

状态：独立预览版。原逐页决策板保留，可随时切回。

## 1. 视觉方向

参考用户提供的界面：冷白与浅灰蓝背景、白色内容卡、清晰而轻的边界、蓝色操作与选择状态、小面积绿色/黄色/红色状态提示。借鉴视觉层级与密度，不引入医疗题材或图片内容。

采用 Ant Design 的文字色阶、字号、控件尺寸与状态逻辑，结合 IBM Carbon 的前景容器与页面背景分层方式，在现有页面控件中实现。文字采用明确的角色色值；功能色集中用于局部操作区，不将所有标题底板染成不同颜色。此次不更换组件框架，不改变数据字段、生成流程和验收语义。

## 2. 信息架构与版本隔离

- 全局策略在前，下方仍为左侧独立滚动的页面目录、右侧单页生成及决策。
- 保留原有模块顺序和父子关系，包括高级视觉设置中的参考图，以及其下的补充说明。
- 原始材料预览/编辑/截图、文字标记、默认策略、占位、真实素材、图片连接、历史图片、采用/取消采用、生成/重试、任务复制等能力全部保留。
- 新版位于独立的 `decision_board_visual_v2` 目录，使用独立的草稿、决策、素材上传目录、任务记录和材料决策版本；原版文件不覆盖。
- 现有生成图沿用项目中的历史图片文件供浏览；本次重构不生成、替换或删除图片。

## 3. 基础设计令牌

| 类别 | 规范 |
| --- | --- |
| 页面背景 | `#E8EDF4` 实色，与白色前景明确分开，不使用接近标题栏的浅渐变 |
| 主卡片 | `#FFFFFF`，1px `#CBD5E1` 边框，10–12px 圆角，轻阴影 |
| 子模块 | `#F5F7FA`，1px `#D6DFE9` 边框，8px 圆角，不增加独立重阴影 |
| 主色 | `#1677FF`；悬停 `#4096FF`；按下 `#0958D9` |
| 选择底色 | `#EDF5FF`，边框 `#69B1FF`，搭配蓝色文字与勾选标识 |
| 文字 | 正文 14–15px；控件/选项 13–14px；辅助信息 12px；当前页标题 26px；模块标题 16px；子模块标题 15px |
| 字重 | 正文 400，重点/标题 500–600；不再普遍使用超粗字重 |
| 控件 | 常规 32px；次级 24–28px；6px 圆角 |
| 间距 | 4 / 8 / 12 / 16 / 24px；主卡内边距 14–16px；子模块 12px |

布局参考 Ant Design 24 栅格的比例原则，按已有 DOM 使用 CSS Grid；不要求用户理解栅格。

## 4. 层级与边界

1. 页面层：全局策略、当前页标题与生成验收区。
2. 顶层模块：每项为独立白色卡片，具有编号、16px 深色加粗标题和清晰的标题下分隔线；标题栏使用白底，模块间距 14px。
3. 子模块：浅中性底板，15px 深色加粗标题，12px 内边距；保持在原父模块内。
4. 选项：白色轻边框；选中状态浅蓝。常规说明保持两三行内的自然阅读，不依靠大面积留白扩张卡片。
5. 辅助说明：右侧或标题附近低权重显示；较长文案保留完整提示与帮助入口。

### 文字角色与对比度

| 角色 | 色值 | 字重与用途 | 白底对比度 |
| --- | --- | --- | --- |
| 标题/重要标签 | `#161616` | 600；模块标题、子模块标题、原文中的重点标签 | 18.1:1 |
| 正文/常规选项 | `#262626` | 400–500；原始材料、选项名称、内容组名称 | 15.1:1 |
| 解释说明 | `#525252` | 400；选项描述、配图说明、操作说明 | 7.8:1 |
| 注释/元信息 | `#667085` | 400；文件时间、辅助提示、折叠说明 | 5.0:1 |
| 交互选择 | `#0958D9` | 与浅蓝选中底配合；不用于所有普通正文 | 随所处状态核对 |

不得将正文套用注释色，不能仅凭字号区分标题与正文。注释保持至少 12px 和可读对比度。禁用、纯装饰信息为独立角色，不将其弱化规则扩展到可操作控件或必读信息。Markdown 编辑文本保持透明以显示高亮层，该高亮层使用正文色；不破坏原有标记呈现。

### 功能区域用色

| 区域 | 背景 / 边界 | 用途 |
| --- | --- | --- |
| 文件同步与保存 | `#E8F6ED` / `#A9D2B8`，路径文字 `#285F41` | 明确标识材料文件操作；文字在此底色上对比度约 6.7:1 |
| 生成与验收 | `#EDF5FF` / `#B9D7FC` | 突出本页生成操作；采用与异常状态保留原语义色 |
| 配色参考输入 | `#F5F7FA` / `#D6DFE9`，标题使用统一标题色 | 与高级视觉设置的其他子模块一致，不作为材料内容依据 |
| 未选选项与材料正文 | 白色 / 清晰的中性边框 | 保证阅读与可操作边界 |
| 选中项 | `#E6F4FF` / `#4096FF` | 统一选择语义，不被父模块颜色替代 |

颜色用于功能分工；顶层标题栏不再使用彩色渐变。当前页页头与主要生成浮标保留蓝色强调，以建立整页视觉重点。

## 5. 状态规范

| 状态 | 视觉 | 行为 |
| --- | --- | --- |
| 默认 | 白底、灰边、深色文字 | 可点击对象具有明确边界 |
| 悬停 | 蓝色边框、极浅底色 | 不进行位移，避免整页跳动 |
| 选中 | 浅蓝底、蓝边、蓝字；图示卡增加勾选 | 同时保留原有选择语义与无障碍状态 |
| 键盘聚焦 | 蓝色外轮廓 | 与选择状态分开；帮助、弹窗和按钮均可识别 |
| 禁用/不可生成 | 灰底灰字 | 保留原有禁用原因；生成入口不隐藏 |
| 加载/生成中 | 沿用原有加载与等待逻辑，蓝色状态 | 不改变任务排队与跨页并行规则 |
| 成功/已采用 | 小面积绿色标识 | 不给整块图片区域铺绿色 |
| 待同步/需重审 | 黄色信息提示 | 保留明确的处理位置说明 |
| 错误/失败 | 红色文字与浅红提示 | 保留具体错误内容和原有重试入口 |
| 空状态 | 紧凑的说明区域 | 保留上传、粘贴、生成等入口 |

## 6. 控件与模块约定

- 全局策略采用左右紧凑分区，最后一行放补充说明；不移到侧栏。
- 页面目录保留独立滚动并占满侧栏；移除全局摘要的界面展示；选中页蓝色底，页码轻底板，状态图标维持原含义。
- 原始材料保留可滚动、可调高的预览/编辑区；截图模式保持固定高度且无内部滚动条。
- Markdown 输入层与标记层使用相同的滚动条占位、换行宽度和末尾空行。标记层始终显示文字与标记；输入层保持透明，提供光标与半透明选区，聚焦和标记后均不遮挡底色。含数字或限定信息的标记直接生效，不弹出重复确认提示。
- 色系描述只说明颜色组合，省略重复类别；内容处理方式使用单行短提示，完整解释保留在悬停提示中。
- 色系卡片统一标题、两行说明、色条和操作栏四行布局；自定义的使用、修改、删除放入独立底部操作栏。按钮横向显示；宽度不足时整张卡片换行，不挤压按钮或拉高同排卡片。长说明截为两行，悬停可读完整内容。
- 自定义色系直接显示五组 HEX 输入与颜色块；点击色块打开页面内的色域、色相、HEX 面板，不再打开系统 RGB 面板。支持鼠标、方向键和浏览器支持的屏幕拾色；无效 HEX 就地提示并阻止保存，不提供渐变设置。
- 单行按钮的文字在控件内垂直居中，折叠标题的箭头与文字共用居中行；输入框统一盒模型，标签和输入区使用明确的紧凑间距。
- 材料状态与隐藏说明合为一处短提示，保留未保存、待同步和错误的操作指引，不保留重复说明和空白占位。
- 图示选项统一图片区域，文字与画面比例、重点突出与画面表达等模块按同样的卡片规则处理；图片不通过变形塞入布局。
- 图集为 4×4 等分，单张图的原始比例为 16:9。显示时宽度自适应、高度按比例计算；图片区域与说明文字分开，说明行不裁切。
- 当前页页头使用 100px 高的蓝色渐变横幅；“前往生成”采用蓝色渐变实心按钮、白字和明显投影。
- 顶层模块使用清楚的白色卡片边界；局部操作区按同步、生成、配色参考等用途采用功能色，选中态统一为蓝色。
- 内容处理选项采用等宽网格，常规宽度至少 88px，长占位状态允许换行；窄屏在保持功能完整的前提下分行显示。
- 内容权重采用紧凑行与分段选项；选项完整保留，长占位状态允许换行。
- 真实素材每行最多五张，图片、名称/移除、关联下拉仍一一对应。
- 参考图左侧粘贴/预览，右侧操作与配色想法；上传按钮与粘贴区分开。
- 参考图两列顶边、底边对齐，空状态消息不占高度；说明与输入框左对齐，使用统一子模块底板。
- 生成图片保留较大的 16:9 预览与历史版本栏；压缩标题、元信息和按钮区，不以牺牲图片可辨认度减少页面高度。
- 设计规范可在新版页头打开；原版通过“打开原版”访问。

## 7. 验收与回退

- 检查旧版文件摘要未改变，新版决策版本路径指向新目录。
- 核对父子模块与原版一致，全部选项与按钮入口完整。
- 检查有图、空状态、编辑态、禁用提示、采用标识、参考图状态，以及桌面与窄屏布局。
- 在同一视口和同一页面比较总高度，记录压缩效果；不改变生成内容、用户选择或已有采用记录来制造差异。
- 新版未确认前不覆盖已安装的默认模板，不上传替换原版。回退时继续打开原版地址即可。
