# Color Preference Sample

Use this file only when the user voluntarily provides preferred PPT screenshots, slide images, or visual references. Do not ask for samples as a normal prerequisite.

## Goal

Extract the user's reusable color taste without copying a complete design system or forcing every future deck into the same palette.

Preference samples are optional calibration. The default workflow must still make an autonomous color decision from the current topic, audience, real images, and page roles.

## Minimum Useful Sample

- 5 to 10 preferred slides are enough for a first pass.
- Fewer slides can still guide one project, but mark the result as tentative.
- Do not ask for examples unless the user explicitly wants personal taste calibration or the brief is too ambiguous to choose a responsible visual direction.

## Extract

For each sample group, describe:

- Background family: light, dark, warm, cool, neutral, photographic, material, or scene-based.
- Accent behavior: restrained, sharp contrast, warm highlight, cool highlight, muted luxury, high-energy, or functional.
- Saturation and brightness: low-saturation, muted midtone, bright clean, deep contrast, or soft atmospheric.
- Material handling: flat, paper-like, glass-light, metal, soft shadow, fine line, dense texture, or photographic depth.
- Color distribution: approximate dominant / secondary / accent / signal ratio.
- Repeated avoidances: colors, gradients, effects, or card styles the user seems not to like.

## Guardrails

- Do not directly reuse a reference palette when the topic, audience, or real images point elsewhere.
- Do not carry sample-derived taste into unrelated decks as a fixed rule.
- Do not turn preference samples into a permanent visual library unless the user explicitly asks.
- Keep page-role variation. Cover, evidence, process, architecture, and closing pages may shift color emphasis while staying in one family.
- Reject results that merely imitate the sample's surface style without improving the current deck's message.
