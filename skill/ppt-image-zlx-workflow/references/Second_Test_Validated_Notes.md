# PPT 图片生成工作流复现备份

备份目的：保存第二次测试中已确认可用的规范、页面指导稿、提示词、主体图和最终带标题图，便于之后复现或继续封装成 skill。

## 已验证流程

1. 用户提供 Excel 大纲和整体风格。
2. 先询问整体风格：暗色系 / 白色系。
3. 严格沿用 Excel 页面标题，不主动重构、改写或压缩标题。
4. 结合 `PPT_Personal_Style.md` 生成 `PPT_Page_Image_Guide.md`，等待人工审阅。
5. 审阅确认后，先生成样张。
6. 样张通过后批量生成主体图。
7. 主体图不生成页面主标题和标题装饰线。
8. 最后用固定母版后处理统一叠加标题和蓝色装饰线。

## 当前关键经验

- 标题一致性不要完全交给图像模型，应通过后处理母版统一叠加。
- 标题安全区必须保持干净，但非文字、非关键信息视觉可以在安全区外进入页眉破型区。
- 真实图片默认必须进入页面，不得用 AI 相似图替代。
- 入图文本采用“锁定文本 + 可扩展文本”机制：关键标题、日期、来源、专有名词锁定；解释性短句允许模型按含义精简扩展，以保证信息丰富度和视觉表现力。
- 页面不能只写“强对齐”，必须明确整体版心、信息栏、主视觉区、底部总结条和组件内部栅格的对齐参照。
- 先生成主体图，再加标题，可以降低标题遮挡内容、跨页标题不一致的问题。

## 目录说明

- `PPT_Personal_Style.md`：当前个人风格规范。
- `project_files/PPT_Page_Image_Guide.md`：本次第二版项目的逐页生成指导稿。
- `project_files/Master_Template.md`：当前母版规则。
- `project_files/outline_source.xlsx`：本次测试使用的大纲源文件。
- `prompts/`：三页实际出图提示词。
- `body_images/`：三页未叠加标题的主体图。
- `final_images/`：三页已叠加统一标题的最终图。

## 当前母版标题参数

- 字体：Microsoft YaHei UI Bold
- 字号：48 px
- 标题位置：x=50, y=36
- 阴影位置：x=53, y=39
- 主蓝线：x=50, y=104, width=90, height=5
- 辅助线：x=145, y=105, width=70, height=2

## 后续建议

后续封装 skill 时，应把本备份中的流程规则、文本控制规则、标题母版后处理规则、文件命名规则和人工确认节点写入 skill 工作流。
